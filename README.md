# Eventos Santarém App

Sistema de gerenciamento de eventos para a cidade de Santarém.

## Estrutura do Projeto

O projeto principal está localizado na pasta `eventos-stm-mvp/`. 

## Instalação e Execução

### 1. Navegue para o diretório do projeto principal
```bash
cd eventos-stm-mvp
```

### 2. Instale as dependências
```bash
npm install
```

### 3. Execute em modo de desenvolvimento
```bash
npm run serve
```

### 4. Compile para produção
```bash
npm run build
```

### 5. Execute linting
```bash
npm run lint
```

## Tecnologias Utilizadas

- Vue.js 3
- Vuetify 3
- Vue Router 4
- Vuex 4
- QR Code Generator

## Funcionalidades

- Listagem de eventos
- Detalhes dos eventos
- Sistema de checkout
- Geração de QR codes
- Confirmação de pagamento
- Interface responsiva
